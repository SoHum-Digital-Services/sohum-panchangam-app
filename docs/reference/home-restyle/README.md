These are React Native Web browser previews, not native device screenshots.

Cards use 106px square images, cream captions with a 52px minimum height, 10px gaps and 16px rail margins. Long labels wrap fully. Eleven original generated illustrations share a traditional devotional style, ivory medallions and plain terracotta rims. Festival images follow API keys; unknown subjects use a neutral diya. Stotrams and mantras share deity artwork, with lingam/bilva subjects for the corresponding hymns. News has a symbolic puja illustration. Prompts and provenance are in `assets/home-illustrations/README.md`. No reference artwork or branding is bundled.

The hero displays one complete stanza from each of the first three API hymns, with dots, sharing and a full-text reader. Mantras are separated using explicit mantra slugs from the stotram API. Monthly observances use only generic recurring observances returned by the festival API; the current response contains none, so a localized availability message appears. Dates are never calculated or invented.

Previews use unchanged public Cheruvugattu stotrams/news GET responses alongside live SoHum panchangam/festival data. Temple requests load independently. The backend excludes the preview origin from CORS; the browser harness supplies those responses with a permissive CORS header only for verification. The app has no proxy or CORS workaround. A Telugu-capable Noto Sans Telugu font is injected only into the preview browser; the app uses device fonts.
